# ジム会費、元とれてる？

今の会費を、実際の利用回数・時間・目的に使えた来館回数と、実在する代替プランから見直すブラウザツールです。本人に料金上限を決めさせず、計算根拠と次の確認候補を示します。

このリポジトリはG1第3回改訂のローカル確認版です。GitHub、Cloudflare、解析サービスには接続しておらず、外部公開もしていません。

## G1第3回改訂でできること

- 独立したホーム画面で、診断の概要、準備物、結果の意味、判断の限界を確認する
- 月会費以外の必須費用が「ない／ある」を明示し、毎月必要な費用と年会費から月額相当を計算する
- 正確な回数、頻度範囲、回数不明を区別し、1回・1時間・目的に使えた来館1回あたりの料金を表示する
- 主な目的に応じた予定回数と実績回数から、利用計画達成率を数値で表示する
- 公式情報で通常料金・必須費用・条件を確認した代替プラン1件について、設備・利用回数・時間帯・店舗範囲の同等性を確認してから月額差と代替価値率を計算する
- 代替が不明でも、現在会費と同額になる都度料金を逆算する
- 利用を妨げた要因から、次の1か月で試すことを一つ示す
- 0回、0円、回数不明、空欄、不正値を安全に扱い、入力を保存・送信しない

全国共通の相場、意味の異なる指標を混ぜた総合点、健康効果の判定、契約変更の自動決定、店舗データベース、履歴保存、解析、外部公開はG1第3回改訂の対象外です。

## 開発

Node.js 24以上を使用します。`package-lock.json`どおりに再現するため、最初に`npm.cmd ci`を実行してください。PowerShellでは実行ポリシーの影響を避けるため、`npm`ではなく`npm.cmd`を使います。

```powershell
npm.cmd ci
npm.cmd run dev
```

表示された`http://127.0.0.1:5173/`をローカル確認に使用します。ホームは`/`、診断は`/check`、計算方法は`/methodology`です。入力値はURLや永続ストレージへ保存されません。

## 品質確認

```powershell
npm.cmd run lint
npm.cmd run typecheck
npm.cmd test
npm.cmd run test:e2e
npm.cmd run build
npm.cmd audit --audit-level=high
```

`npm.cmd run check`で、lint、型、単体・部品テスト、本番ビルド、Playwright Testをまとめて実行できます。Playwright TestはChromeを使い、390px、768px、1280pxで主要導線を確認します。
