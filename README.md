# ジム会費、元とれてる？

今の会費を、来館回数だけでなく、実際に使った設備・プログラム・温浴・交流・通いやすさなど、本人が残したい複数の価値から見直すブラウザツールです。料金の事実と本人の価値判断を分け、結論の理由と次に確認する一つを示します。

このリポジトリはG1第5回改訂のローカル確認版です。GitHub、Cloudflare、解析サービスには接続しておらず、外部公開もしていません。

## G1第5回改訂でできること

- 独立したホーム画面で、診断の概要、準備物、結果の意味、判断の限界を確認する
- 月会費以外の必須費用が「ない／ある」を明示し、毎月必要な費用と年会費から月額相当を計算する
- 正確な来館回数、おおよその回数範囲、回数不明を区別し、分かる範囲で1回あたり料金を表示する
- 回数不明でも、1・2・4・8・12回利用した場合の料金シナリオを示し、価値の診断は通常どおり完了する
- 任意の館内利用時間から1時間あたり料金を表示する。館内利用時間には着替え、運動、クラス、プール、風呂・サウナ、休憩を含められる
- トレーニング設備、スタジオ、プール、温浴・サウナ、指導、交流、通いやすさ等を複数選択する
- 選んだ価値ごとに、利用頻度、期待どおり使えたか、会費を払って残したい理由かを別々に確認する
- 来月も選びたいかと費用負担を判定へ接続し、回数だけを理由に本人が重視する価値を否定しない
- 価値が弱い、費用負担がある、または継続を迷う場合だけ阻害要因を聞き、次の一行動を変える
- 算出できない料金指標は、来館回数または館内利用時間のどちらが不足したかを具体的に示す
- 0回、0円、回数不明、空欄、不正値を安全に扱い、入力を保存・送信しない

全国共通の相場、活動種類への独自金額倍率、意味の異なる指標を混ぜた総合点、健康・医療上の判定、他施設候補の料金比較、契約変更の自動決定、店舗データベース、履歴保存、解析、外部公開はG1第5回改訂の対象外です。

## 開発

Node.js 24以上を使用します。`package-lock.json`どおりに再現するため、最初に`npm.cmd ci`を実行してください。PowerShellでは実行ポリシーの影響を避けるため、`npm`ではなく`npm.cmd`を使います。

```powershell
npm.cmd ci
npm.cmd run dev
```

表示された`http://127.0.0.1:5173/`をローカル確認に使用します。ホームは`/`、診断は`/check`、計算方法は`/methodology`です。入力値はURLや永続ストレージへ保存されません。

## 品質確認

```powershell
npm.cmd run lint
npm.cmd run typecheck
npm.cmd test
npm.cmd run test:e2e
npm.cmd run build
npm.cmd audit --audit-level=high
```

`npm.cmd run check`で、lint、型、単体・部品テスト、本番ビルド、Playwright Testをまとめて実行できます。Playwright TestはChromeを使い、390px、768px、1280pxで主要導線を確認します。
