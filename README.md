# ジム会費、元とれてる？

月会費を、1回あたり、1時間あたり、使った設備・プログラム、続けやすさのうち自分が選んだ基準で見直すブラウザツールです。回数を覚えていない場合も、頻度範囲や回数別シナリオから確認できます。

このリポジトリは改訂G1のローカル確認版です。GitHub、Cloudflare、解析サービスには接続しておらず、外部公開もしていません。

## 改訂G1でできること

- 先月実数、頻度範囲、回数不明の3方式から1回あたり料金を確認する
- 合計滞在時間、または平均滞在時間から1時間あたり料金を確認する
- 実際に使った設備・プログラムと、会費を払う理由として重要なものを分けて整理する
- 料金以外で失いたくない条件を、採点や金額換算なしで確認する
- 月会費、毎月必須の固定費、年会費等を月額相当にまとめる
- 0回、空欄、不正値を安全に扱い、入力を保存・送信しない

都度払い、別月額、回数券との比較、単一の得点、継続・退会の推奨、履歴保存、解析、外部公開は改訂G1の対象外です。

## 開発

Node.js 24以上を使用します。`package-lock.json`どおりに再現するため、最初に`npm.cmd ci`を実行してください。PowerShellでは実行ポリシーの影響を避けるため、`npm`ではなく`npm.cmd`を使います。

```powershell
npm.cmd ci
npm.cmd run dev
```

## 品質確認

```powershell
npm.cmd run lint

```
