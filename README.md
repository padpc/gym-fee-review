# ジム会費、元とれてる？

今の会費を、実際の支払額、来館、会費を払う理由として重要だった利用、その期待、家計への負担から見直すブラウザツールです。回答を並べるだけでなく、続ける根拠と見直す根拠を分け、結論と次にする一つを示します。

このリポジトリはG1第7回改訂のローカル確認版です。GitHub、Cloudflare、解析サービスには接続しておらず、外部公開もしていません。

## G1第7回改訂でできること

- 独立したホーム画面で、料金・利用・期待・負担を照合する診断の概要を確認する
- 基本月会費、毎月必須の追加費用、年会費・更新料を最初に分けて入力し、二重入力や一時費用を除外する
- 追加費用と年会費は「ない／金額が分かる／分からない」を個別に選び、未確認を0円と断定しない
- 確定した実質月額または入力済み分の月額を、家計への負担を答える前に表示する
- 正確な来館回数、おおよその回数範囲、回数不明を区別し、分かる範囲で1回あたり料金を表示する
- 回数不明でも、1・2・4・8・12回利用した場合の料金シナリオを示し、価値の診断は通常どおり完了する
- 任意の館内利用時間から1時間あたり料金を表示する。時間には着替え、運動、クラス、プール、風呂・温泉・サウナ、休憩を含める
- 会費を払う理由として最も重要な利用を1件、追加を2件まで選び、項目ごとに期待との一致を1回だけ確認する
- 「利用したが内容・質が期待以下」と「利用したかったが、ほぼ使えなかった」を分け、トレーニングの質や利用できなかった状態を区別する
- 結論、支える根拠、見直す根拠、料金、次の一行動の順に、回答の再掲ではなく関係をまとめて表示する
- 算出できない料金指標は、来館回数または館内利用時間のどちらが不足したかを具体的に示す
- 0回、0円、回数不明、空欄、不正値を安全に扱い、入力を保存・送信しない

全国共通の相場、活動種類への独自金額倍率、意味の異なる指標を混ぜた総合点、健康・医療上の判定、他施設候補の料金比較、契約変更の自動決定、店舗データベース、履歴保存、解析、外部公開はG1第7回改訂の対象外です。

## 開発

Node.js 24以上を使用します。`package-lock.json`どおりに再現するため、最初に`npm.cmd ci`を実行してください。PowerShellでは実行ポリシーの影響を避けるため、`npm`ではなく`npm.cmd`を使います。

```powershell
npm.cmd ci
npm.cmd run dev
```

表示された`http://127.0.0.1:5173/`をローカル確認に使用します。ホームは`/`、診断は`/check`、計算方法は`/methodology`です。入力値はURLや永続ストレージへ保存されません。

## 品質確認

```powershell
npm.cmd run lint
npm.cmd run typecheck
npm.cmd test
npm.cmd run test:e2e
npm.cmd run build
npm.cmd audit --audit-level=high
```

`npm.cmd run check`で、lint、型、単体・部品テスト、本番ビルド、Playwright Testをまとめて実行できます。Playwright TestはChromeを使い、390px、768px、1280pxで主要導線を確認します。
