# ジム会費、元とれてる？

今の会費を、実際の支払額、来館、会費を払う理由として重要だった利用、その期待、家計への負担から見直すブラウザツールです。回答を並べるだけでなく、続ける根拠と見直す根拠を分け、結論と診断後に確認する内容を示します。

このリポジトリは、利用者受入済みのG1第9回改訂を無料初版として固定し、G3の公開候補を準備している状態です。3ページの検索メタデータ、実404、OGP、セキュリティヘッダー、Cloudflare Workers Static Assets設定、匿名イベントAPI、匿名のMicrosoft Forms意見導線を含みます。Git remote、実D1、Web Analyticsには未接続で、外部公開もしていません。

## 無料初版でできること

- 製品名と「ダンベル＋チェック」のローカルSVGファビコンでジムの診断製品だと識別し、主要導線は通常・ホバー・押下・現在地で位置・色面・影が変わるタブとして見分ける。390pxでも高さ44px以上の導線から各画面へ移動できる
- フッターは上部タブと重複しない補助リンクとし、計算方法ページ末尾には重複する診断ボタンを置かない
- 計算方法ページでは、番号付きのページ内目次、実質月額9,000円・1回あたり1,125円・1時間あたり750円の計算例、同じ会費でも結論が変わる比較例、4つの結論の代表条件を図式化して確認できる
- 独立したホーム画面で、料金・利用・期待・負担を照合する診断の概要を確認する
- 基本月会費、毎月必須の追加費用、年会費・更新料を最初に分けて入力し、二重入力や一時費用を除外する
- 追加費用と年会費は「なし／あり」を個別に選び、「あり」なら金額を必須入力する
- 料金3区分がすべて確定したときだけ実質月額を、家計への負担を答える前に表示する
- 正確な来館回数、おおよその回数範囲、回数不明を区別し、分かる範囲で1回あたり料金を表示する
- 回数不明でも、1・2・4・8・12回利用した場合の料金シナリオを示し、価値の診断は通常どおり完了する
- 任意の館内利用時間から1時間あたり料金を表示する。時間には着替え、運動、クラス、プール、風呂・温泉・サウナ、休憩を含める
- 会費を払う理由として最も重要な利用を1件、追加を2件まで選び、利用ごとに意味の合う質問と5段階の回答で期待との一致を確認する
- たとえばスタジオは「参加」、指導は「受ける」、通いやすさは「生活に合う」という言葉を入力と結果理由で一貫して使う
- 結論、支える根拠、見直す根拠、料金、診断後の確認の順に、回答の再掲ではなく関係をまとめて表示する
- 診断後の確認では、何を、いつ、料金表・会員ページ・契約書・カレンダーのどこで確認するかを一つ示す
- 算出できない料金指標は、来館回数または館内利用時間のどちらが不足したかを具体的に示す
- 0回、0円、回数不明、空欄、不正値を安全に扱い、入力を保存・送信しない

全国共通の相場、活動種類への独自金額倍率、意味の異なる指標を混ぜた総合点、健康・医療上の判定、他施設候補の料金比較、契約変更の自動決定、店舗データベース、履歴保存は無料初版の対象外です。

## 開発

Node.js 24以上を使用します。`package-lock.json`どおりに再現するため、最初に`npm.cmd ci`を実行してください。PowerShellでは実行ポリシーの影響を避けるため、`npm`ではなく`npm.cmd`を使います。

```powershell
npm.cmd ci
npm.cmd run dev
```

表示された`http://127.0.0.1:5173/`をローカル確認に使用します。ホームは`/`、診断は`/check`、計算方法は`/methodology`です。入力値はURLや永続ストレージへ保存されません。

## 品質確認

```powershell
npm.cmd run lint
npm.cmd run typecheck
npm.cmd test
npm.cmd run test:e2e
npm.cmd run build
npm.cmd audit --audit-level=high
```

`npm.cmd run check`で、lint、型、単体・部品テスト、本番ビルド、Playwright Test、Cloudflare dry-runをまとめて実行できます。Playwright TestはChromeを使い、390px、768px、1280pxに加えて320px相当の主要導線を確認します。

## 公開候補のローカル確認

`wrangler.jsonc`のD1 IDは公開前停止用のゼロ値です。登録済みCloudflareアカウントで実D1を作成し、IDを置き換えるまでデプロイしてはいけません。Web Analyticsのsite tokenは公開用ビルド環境の`VITE_CLOUDFLARE_WEB_ANALYTICS_TOKEN`へ設定します。

```powershell
npm.cmd run deploy:dry-run
npx.cmd wrangler d1 migrations apply gym-fee-review-events --local
npm.cmd run preview:worker -- --port 8787
```

意見フォームは`pad pc / hostmy@outlook.jp`所有のMicrosoft Formsで作成し、ログイン不要、氏名・メールアドレスの自動取得なし、通知なしの回答画面を外部Chromeで確認済みです。公開URLは`src/releaseConfig.ts`にだけ設定し、サイト入力や診断結果を付加しません。公開・復旧の停止点と手順は[RELEASE.md](./RELEASE.md)を参照してください。
