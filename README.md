# ジム会費、元とれてる？

今の会費を、利用者自身の料金基準と入会目的の達成度から見直すブラウザツールです。料金面と利用価値を別々に判定し、根拠を示します。

このリポジトリはG1第2回改訂のローカル確認版です。GitHub、Cloudflare、解析サービスには接続しておらず、外部公開もしていません。

## G1第2回改訂でできること

- 月会費、毎月必須の固定費、年会費等から月額相当を計算する
- 自分の月額上限、自分の1回上限、実在する代替案の月額相当1件から料金基準を選ぶ
- 1回上限を選んだ場合だけ、先月実数、頻度範囲、回数不明の3方式で利用回数を扱う
- 主な入会目的、その達成度、他での代替しにくさから利用価値の根拠を確認する
- 料金と利用価値の状態を2枚の独立カードと根拠付きの主結果で表示する
- 0回、0円、回数不明、空欄、不正値を安全に扱い、入力を保存・送信しない

全国共通の相場、総合点、健康効果、来館回数の増加、継続・休会・退会の推奨、店舗データベース、履歴保存、解析、外部公開はG1第2回改訂の対象外です。

## 開発

Node.js 24以上を使用します。`package-lock.json`どおりに再現するため、最初に`npm.cmd ci`を実行してください。PowerShellでは実行ポリシーの影響を避けるため、`npm`ではなく`npm.cmd`を使います。

```powershell
npm.cmd ci
npm.cmd run dev
```

表示された`http://127.0.0.1:5173/`をローカル確認に使用します。入力値はURLや永続ストレージへ保存されません。
