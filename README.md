# ジム会費、元とれてる？

今の会費を、来館回数だけでなく、目的に合う活動を行った回数、予定内容を完了できた回数、確認できた変化、実際に使ったサービスから見直すブラウザツールです。計算根拠と、次に変える一つを示します。

このリポジトリはG1第4回改訂のローカル確認版です。GitHub、Cloudflare、解析サービスには接続しておらず、外部公開もしていません。

## G1第4回改訂でできること

- 独立したホーム画面で、診断の概要、準備物、結果の意味、判断の限界を確認する
- 月会費以外の必須費用が「ない／ある」を明示し、毎月必要な費用と年会費から月額相当を計算する
- 正確な回数、頻度範囲、回数不明を区別し、来館・目的活動・内容完了それぞれの1回単価を表示する
- 活動利用率と内容完了率を表示し、活動に合う内容だったか、目的に沿う変化があったかを別々に確認する
- 実際に使ったクラス、プール、指導、専門設備等を、現在プランで保持したい条件として扱う
- 同じ条件なら来月も選びたいかを判定へ接続し、安全上の懸念を他の結論より優先する
- 問題がある場合だけ阻害要因を聞き、次の1か月で試すことを一つ示す
- 公式情報を確認した代替プラン1件を任意で入力し、目的活動回数と必要条件から料金差を計算する
- 代替が不明でも基本診断を完了し、得・損を断定せず、分かる場合だけ同額になる目的活動1回料金を示す
- 0回、0円、回数不明、空欄、不正値を安全に扱い、入力を保存・送信しない

全国共通の相場、活動種類への独自金額倍率、意味の異なる指標を混ぜた総合点、健康効果の判定、契約変更の自動決定、店舗データベース、履歴保存、解析、外部公開はG1第4回改訂の対象外です。

## 開発

Node.js 24以上を使用します。`package-lock.json`どおりに再現するため、最初に`npm.cmd ci`を実行してください。PowerShellでは実行ポリシーの影響を避けるため、`npm`ではなく`npm.cmd`を使います。

```powershell
npm.cmd ci
npm.cmd run dev
```

表示された`http://127.0.0.1:5173/`をローカル確認に使用します。ホームは`/`、診断は`/check`、計算方法は`/methodology`です。入力値はURLや永続ストレージへ保存されません。

## 品質確認

```powershell
npm.cmd run lint
npm.cmd run typecheck
npm.cmd test
npm.cmd run test:e2e
npm.cmd run build
npm.cmd audit --audit-level=high
```

`npm.cmd run check`で、lint、型、単体・部品テスト、本番ビルド、Playwright Testをまとめて実行できます。Playwright TestはChromeを使い、390px、768px、1280pxで主要導線を確認します。
